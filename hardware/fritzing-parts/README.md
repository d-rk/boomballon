# hardware/fritzing-parts/

Custom Fritzing parts (`.fzpz`) for BoomBalloon's own PCBs, so they can be dragged into
a Fritzing sketch like any other part instead of only existing as standalone board
designs. Generated by `media/pcb/parts/generate_<board>.py` from the board's real
Gerber data -- see `media/CLAUDE.md` for how.

To use: in Fritzing, drag a `.fzpz` file from this folder onto the canvas (or
File > Open it once to install it into your parts bin). Each part's breadboard-view
graphic is the real photorealistic PCB render; its connector pins are placed at the
real header positions, labeled with the same pin names used in
`docs/src/build-guide/wiring.md`.

Steuermodul is not here -- it's reused directly from `hardware/control/Steuermodul.fzz`,
which already has full real detail (Arduino + TIP120s) in its own breadboard view.

See `hardware/system-wiring/BoomBalloon-Wiring.fzz` for a starter sketch with everything
already placed.

## Known gap: Fotomodul's "Connector" pass-through

`Fotomodul.fzpz` has 9 connectors (`FM` 7-pin + `LM` 2-pin) but is missing the 6-pin
`Connector` pass-through for the Displaymodul cable that `docs/src/build-guide/modules/card-reader.md`
documents and that's visibly present on the real assembled boards
(`docs/src/assets/img/gallery/fotomodul-assembled.jpg`). It isn't a component in
`hardware/card-reader/Kartenleser_Fotomodul.fzz` -- confirmed by listing every part
instance in that sketch -- so there's no Gerber data to place it from. The Fritzing
source and the as-built boards have drifted apart for this one connector. If it matters
for the wiring diagram, it'll need to be added by hand in Fritzing (or the source sketch
updated first).
